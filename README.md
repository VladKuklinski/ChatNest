# ChatNest

ChatNest is a lightweight and modern chat application built with Swift (SwiftUI).  
It allows users to register, send messages, add friends and manage incoming/outgoing requests in real-time.

## Features

- 🔐 User authentication (email/password, Facebook login)
- 💬 Real-time messaging
- 👥 Friends management (add/remove friends, incoming/outgoing requests)
- 🟢 Online/offline friend status tracking
- 📱 Clean and responsive SwiftUI interface
